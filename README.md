# Тестирование веб-приложения Stellar Burgers

Этот проект содержит автоматизированные тесты для проверки ключевых функций веб-приложения Stellar Burgers.

---

## Проверяемые функциональности

### 1. Регистрация пользователя
- Успешная регистрация с валидными данными:
  - Поле «Имя» не пустое.
  - Email в корректном формате (например, `123@ya.ru`).
  - Пароль минимум 6 символов.
- Обработка ошибки при вводе некорректного пароля.

### 2. Вход в аккаунт
- Вход через кнопку **«Войти в аккаунт»** на главной странице.
- Вход через кнопку **«Личный кабинет»**.
- Вход через кнопку в форме регистрации.
- Вход через кнопку в форме восстановления пароля.

### 3. Переход в личный кабинет
- Переход по клику на **«Личный кабинет»** с главной страницы.

### 4. Переход из личного кабинета в конструктор
- Переход по клику на **«Конструктор»**.
- Переход по клику на логотип **Stellar Burgers**.

### 5. Выход из аккаунта
- Выход по кнопке **«Выйти»** в личном кабинете.

### 6. Раздел «Конструктор»
- Проверка работы вкладок:
  - **«Булки»**
  - **«Соусы»**
  - **«Начинки»**
- При клике происходит сдвиг содержимого вправо или влево к выбранной категории.
- Активная вкладка визуально выделена (например, синим подчеркиванием и классом `tab_tab_type_current__2BEPc`).
